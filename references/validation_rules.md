# 合规校验规则（v7.1 科技推广趣味风格版本）

## 概述

FireSpot 在阶段5执行严格的质量校验，确保输出的文章符合专业标准。

**v7.1 新增**：科技推广趣味风格校验，确保文章自然、有趣、大白话。

## 校验维度

### 1. 字数检查

**规则**：
- 最低字数：800字（正文）
- 建议字数：800-1500字
- 警告字数：>2000字

**评分影响**：
- 不足800字：-20分
- 超过2000字：-5分

**错误级别**：
- 不足800字：`error`
- 超过2000字：`warning`

### 2. 禁用句式检测

#### 2.1 基础禁用列表（通用）

**禁用列表**：

| 模式 | 描述 | 评分影响 |
|------|------|----------|
| `大家好，今天给大家分享` | 陈词滥调的开场白 | -5分/次 |
| `首先.*?其次.*?最后` | 机械的过渡词 | -5分/次 |
| `相信很多小伙伴` | 套话表达 | -5分/次 |
| `话不多说，直接上干货` | 网络用语 | -5分/次 |
| `让我们一起来看看` | 无意义的过渡 | -5分/次 |
| `众所周知` | 缺乏具体性 | -5分/次 |
| `毋庸置疑` | 缺乏论证 | -5分/次 |

**错误级别**：全部为 `warning`

#### 2.2 v7.1 新增：学术化表达禁用列表（严格禁止）

**❌ 严格禁止的学术化表达**：

| 模式 | 描述 | 评分影响 | 错误级别 |
|------|------|----------|----------|
| `近年来，随着.*?的发展` | 学术化开篇陈词 | -10分/次 | error |
| `本文将从.*?维度.*?分析` | 学术化框架表述 | -10分/次 | error |
| `综上所述，.*?具有重要意义` | 学术化结尾陈词 | -10分/次 | error |
| `值得注意的是` | 公文式过渡 | -5分/次 | warning |
| `让我们深入探讨` | 套话过渡 | -5分/次 | warning |
| `毋庸置疑` | 缺乏论证的断言 | -5分/次 | warning |
| `不可否认` | 缺乏论证的断言 | -5分/次 | warning |

**评分说明**：
- 这些表达会让文章显得严肃、学术化，失去趣味性
- 优先级高于基础禁用列表
- 一旦发现将严重影响评分

#### 2.3 v7.1 新增：机械句式禁用列表（严格禁止）

**❌ 严格禁止的机械句式（新增）**：

| 模式 | 描述 | 评分影响 | 错误级别 |
|------|------|----------|----------|
| `不在.*?而在.*?` | 机械式定位句式 | -10分/次 | error |
| `不是.*?而是.*?` | 机械式否定肯定句式 | -10分/次 | error |
| `一个容易被忽视的` | 套路化引入 | -10分/次 | error |
| `一个不争的事实是` | 僵硬表达 | -10分/次 | error |
| `第一.*?第二.*?第三` | 机械式罗列 | -10分/次 | error |

**为什么这些句式问题严重？**
这些句式让文章显得极其僵硬、不自然，读者一眼就能看出是AI写的：
- "不在...而在..." 这种句式在文章中频繁出现，会让文章显得机械教条
- "不是...而是..." 的重复使用会让段落的起承转折非常生硬
- "一个容易被忽视的..." 是AI常用的套路化引入方式
- 这些表达方式让读者读起来非常别扭，严重影响阅读体验

#### 2.4 v7.1 更新：低级AI味表达禁用列表

**❌ 严格禁止的低级AI味表达**：

| 模式 | 描述 | 评分影响 | 错误级别 |
|------|------|----------|----------|
| `说白了` | 最明显的AI味标志 | -10分/次 | error |
| `说人话就是` | 刻意强调通俗 | -10分/次 | error |
| `你可能不知道` | 套路化悬念制造 | -10分/次 | error |
| `绝了` / `离谱` | 情绪化夸张 | -5分/次 | warning |
| `太秀了` / `这波操作` | 网络用语堆砌 | -5分/次 | warning |
| `单身狗` / `扎心了吗` | 刻意调侃 | -5分/次 | warning |

**注意**：这些表达在v7.1中已从"加分项"改为"扣分项"，因为它们是低级AI味的标志。

### 3. 图片锚点检查

**必需锚点**：
- `cover_01` - 封面图（必须）
- `inline_01`, `inline_02` - 正文配图（至少2张）
- `quote_01` - 金句图（建议）

**检查项**：

1. **锚点存在性**
   - 未发现任何锚点：`error` (-15分)

2. **封面资产**
   - 缺少 `cover_01`：`error` (-15分)

3. **锚点-资产匹配**
   - 锚点未在 `stage4_article.json` 中声明：`error` (-15分)
   - 资产列表中有重复 `asset_id`：`error` (-15分)

4. **正文配图数量**
   - 少于2张 `inline_*`：`warning` (-5分)

5. **金句图**
   - 缺少 `quote_01`：`info` (不扣分)

### 4. 段落结构检查

**检查项**：

1. **长段落检测**
   - 定义：>300字符的段落
   - 警告：超过3个长段落 → `info`

2. **标题长度**
   - 限制：64字
   - 超出：`warning` (-5分)

3. **段落数量**
   - 记录但不限制

4. **章节标题数量**
   - 记录但不限制

### 5. v7.1 新增：科技推广趣味风格检查

#### 5.1 标题风格检查

**检查项**：

1. **数据冲击检测**
   - 检查标题是否包含具体数字
   - 示例：`100万`、`80%`、`年营收破亿`
   - 包含数据：`info` (加分项)
   - 不包含：不扣分

2. **悬念制造检测**
   - 检查标题是否包含疑问句
   - 示例：`就这？`、`你敢信？`、`这波操作太秀了`
   - 包含悬念：`info` (加分项)
   - 不包含：不扣分

3. **学术化标题检测**
   - 检查标题是否过于学术化
   - 模式：`.*?技术.*?研究$`、`.*?深度解析.*?$`
   - 发现学术化标题：`warning` (-10分)

#### 5.2 开篇风格检查

**检查项**：

1. **生活场景切入检测**
   - 检查开篇是否从具体场景切入
   - 模式：`举个例子`、`想象一下`、`你可能不知道`
   - 包含场景化：`info` (加分项)

2. **学术化开篇检测**
   - 检查开篇是否使用学术化表达
   - 模式：`近年来，随着`、`本文将从`
   - 发现学术化开篇：`error` (-15分)

#### 5.3 口语化表达检查

**检查项**：

1. **通俗化表达统计**
   - 统计"说人话就是"、"说白了"等表达次数
   - 不少于2次：`info` (加分项)
   - 0次：`warning` (-5分)

2. **案例说明统计**
   - 统计"举个例子"、"想象一下"等表达次数
   - 不少于2次：`info` (加分项)
   - 0次：`warning` (-5分)

3. **技术名词通俗化检查**
   - 检测技术术语后是否跟通俗解释
   - 技术术语：`深度学习`、`神经网络`、`自然语言处理`、`机器学习`
   - 术语后无解释：`warning` (-3分/个)

#### 5.4 语气调性检查

**检查项**：

1. **调侃表达统计**
   - 统计"绝了"、"离谱"、"太秀了"等表达次数
   - 适度使用（1-3次）：`info` (加分项)
   - 过度使用（>5次）：`warning` (-3分)

2. **网络热词使用检查**
   - 统计"这波操作"、"闷声发大财"等网络热词
   - 适度使用（1-2次）：`info` (加分项)
   - 过度使用（>4次）：`warning` (-3分)

#### 5.5 结尾升华检查

**检查项**：

1. **讨论空间检查**
   - 检查结尾是否留有讨论话题
   - 模式：`你怎么看？`、`欢迎在评论区`
   - 包含讨论空间：`info` (加分项)

2. **学术化结尾检测**
   - 检查结尾是否使用学术化表达
   - 模式：`综上所述`、`具有重要意义`
   - 发现学术化结尾：`error` (-15分)

#### 5.6 趣味性综合评分

**评分规则**：
- 基础分：100分
- 科技推广风格加分：+15分（通过各项检查）
- 学术化表达扣分：-20分（发现学术化表达）
- 最终趣味性分数：0-100分

**趣味性等级**：
- 90-100分：`优秀` - 科技推广风格鲜明
- 75-89分：`良好` - 有一定趣味性
- 60-74分：`及格` - 趣味性不足
- <60分：`需改进` - 过于严肃学术化

## 评分系统

### 总分计算

```
初始分：100分
- 字数扣分
- 禁用句式扣分
- 图片锚点扣分
- 标题长度扣分
= 最终分数（最低0分）
```

### 状态判定

| 条件 | 状态 |
|------|------|
| 分数 ≥ 80 且无 error | `pass`（通过） |
| 其他 | `review`（需审核） |

{
  "score": 85,

  "paragraph_count": 15,
  "heading_count": 4,

    }
  ],
  "warnings": [
    {
      "level": "warning",

### 问题级别说明

- **error**：必须修复，否则无法通过
- **warning**：强烈建议修复，扣5-20分
- **info**：仅供参考，不扣分

## 最佳实践

### v7.1 科技推广趣味风格写作指南

#### 八大写作原则

1. **说人话，不讲术语** - 技术名词必配通俗解释
2. **讲故事，不只罗列** - 用案例和场景替代抽象概念
3. **有态度，不居高临下** - 像朋友交流，不像老师上课
4. **有趣味，不失专业** - 该调皮时调皮，该严肃时严肃
5. **有数据，不堆砌数字** - 数据要有冲击力，但不是报告
6. **有观点，留讨论空间** - 不说教，给读者思考余地
7. **懂网络，不滥用梗** - 适度使用网络表达，不过度
8. **懂读者，尊重智商** - 不说废话，不解释常识

#### 避免禁用句式

**替代方案**：

| 禁用句式 | 推荐替代 |
|----------|----------|
| "大家好，今天给大家分享" | 直接进入主题 |
| "首先...其次...最后" | 使用小标题或数字标记 |
| "相信很多小伙伴" | "很多人" 或具体场景描述 |
| "话不多说，直接上干货" | 删除，直接展示内容 |
| "让我们一起来看看" | 删除，直接开始描述 |
| "众所周知" | 引用具体数据或案例 |
| "毋庸置疑" | 删除或提供论证 |

#### v7.1 新增：学术化表达替代方案

**❌ 严格禁止的学术化表达 → ✅ 科技推广风格替代**：

| 禁用句式（学术化） | 推荐替代（科技推广风格） |
|----------|----------|
| "近年来，随着XX技术的不断发展" | "说人话就是：现在的XX已经..." |
| "本文将从技术原理、应用场景和发展趋势三个维度进行分析" | "举个例子：你可能在生活中已经遇到过..." |
| "综上所述，该技术具有广阔的应用前景" | "所以啊，与其...不如想想怎么..." |
| "值得注意的是" | "你可能不知道："、"其实很多小伙伴都不知道" |
| "让我们深入探讨" | "想象一下："、"说白了" |
| "毋庸置疑" | 删除或提供具体论证 |

#### v7.1 科技推广风格表达模板

**常用表达模板（推荐使用）**：

```
• "说人话就是：[技术名词]的通俗解释"
• "举个例子：[生活场景的类比]"
• "你可能不知道：[反常识的事实]"
• "这波操作：[对某个技术/设计的评价]"
• "说白了：[核心概念的简化解释]"
• "想象一下：[场景化描述]"
• "其实：[纠正误区]"
```

**口语化表达（适度使用）**：

```
• 调侃类："这设计绝了"、"离谱"、"离离谱"、"太秀了"
• 过渡类："想象一下"、"举个例子"、"说白了"
• 悬念类："其实"、"你可能不知道"、"说人话就是"
• 网络热词："这波操作"、"闷声发大财"（1-2次为宜）
```

#### 标题创作技巧

**科技推广风格标题公式**：

1. **数据冲击 + 悬念**
   - 《卖爆100万台！这些"小而美"的AI硬件正在闷声发大财》
   - 《年营收破亿！从灭蚊高手到智能项圈的市场突围》

2. **疑问句 + 挑衅式表达**
   - 《AI写诗都比你好？这波操作我看傻了》
   - 《苹果最AI的新机，就这？》

3. **对比 + 反差**
   - 《从灭蚊高手到智能项圈，猎奇AI硬件的市场突围》
   - 《小而美却大成功：这些AI硬件正在闷声发大财》

**❌ 避免的标题风格**：
- 《XX技术在YY领域的应用研究》
- 《XX技术的深度解析与应用前景》
- 《关于XX技术的思考》

#### 开篇钩子技巧

**科技推广风格开篇公式**：

1. **生活场景切入**
   - "说人话就是：现在的AI已经能看懂你在说什么，甚至比你更会表达。"

2. **反常识观点**
   - "你可能不知道，其实XX技术早就渗透到你的生活里了。"

3. **具体案例**
   - "举个例子：你让AI写首情诗，它可能比你这个单身狗写得更动人（扎心了吗）。"

**❌ 避免的开篇风格**：
- "近年来，随着XX技术的不断发展..."
- "本文将从技术原理、应用场景和发展趋势三个维度进行深入分析。"

#### 结尾升华技巧

**科技推广风格结尾公式**：

1. **留讨论话题**
   - "你怎么看？欢迎在评论区分享你的观点。"

2. **给实用建议**
   - "所以啊，与其担心被AI取代，不如想想怎么和AI配合，一起搞点大事情。"

3. **制造期待**
   - "接下来的发展更有意思，让我们拭目以待。"

**❌ 避免的结尾风格**：
- "综上所述，该技术具有广阔的应用前景和重要的研究价值。"

### 控制字数

- **开篇**：100-150字
- **主体**：600-1000字（3个段落，每段200-350字）
- **结语**：100-150字
- **总计**：800-1500字

### 优化段落节奏

- 每段3-5行
- 避免"豆腐块"式密集文字
- 关键观点单独成段
- 使用列表、引用等格式

### 图片规划

- 必须包含封面图
- 至少2-3张正文配图
- 建议包含1张金句图
- 确保锚点和资产一一对应
